# KosherLink – וואטסאפ במחשב לבעלי טלפון כשר

תוכנה קטנה ל־Windows 11 (כ־60KB) שמאפשרת להשתמש בוואטסאפ במחשב עם מספר של טלפון כשר.
האימות נעשה **בשיחה קולית** לטלפון הכשר.

## ⬇️ הורדה והתקנה

1. **[להורדת KosherLink.exe](https://github.com/KatzChaim/KosherLink/releases/latest/download/KosherLink.exe)** (הגרסה האחרונה תמיד). אפשר גם להוריד [חבילה עם קובץ הוראות](https://github.com/KatzChaim/KosherLink/releases/latest/download/KosherLink.zip).
2. מעבירים את הקובץ לתיקייה קבועה, למשל `מסמכים\KosherLink`, ומפעילים אותו.
3. אם מופיע "Windows הגן על המחשב", לוחצים "מידע נוסף" ואז "הפעל בכל זאת". האזהרה מופיעה כי התוכנה עוד לא חתומה דיגיטלית.
4. האשף מוביל את כל השאר: התקנה אוטומטית, אחר כך רישום בשיחה קולית, ובסוף חיבור לוואטסאפ ל־Windows.

אחרי ההתקנה התוכנה מתעדכנת לבד מדף ה־[Releases](https://github.com/KatzChaim/KosherLink/releases), וגם וואטסאפ שבתוכה מתעדכן לבד.

## איך זה עובד

- התוכנה מורידה רכיבים **רשמיים בלבד**: האמולטור ואנדרואיד 11 נקי (AOSP, בלי שירותי Google) של Google, וואטסאפ לאנדרואיד מהאתר של וואטסאפ, ו־WhatsApp ל־Windows מהחנות של מיקרוסופט.
- היא מריצה ברקע "טלפון וירטואלי" קטן, **בלי חלון**, עם עדיפות נמוכה, בלי אנימציות ועם מסך כבוי. כך הוא כמעט לא מורגש.
- וואטסאפ בטלפון הווירטואלי הוא "הטלפון הראשי". וואטסאפ ל־Windows מחובר אליו כמו לטלפון רגיל.
- **עדכונים:** כל 12 שעות התוכנה בודקת ב־whatsapp.com אם יש גרסה חדשה ומתקינה אותה לבד. וואטסאפ ל־Windows מתעדכן דרך החנות. **התוכנה עצמה** בודקת פעם ביום אם יש Release חדש ב־GitHub, ואם יש, היא מורידה אותו, בודקת שהקובץ תקין, ומפעילה את עצמה מחדש.
- **המידע נשמר רק במחשב**, בתיקייה `%LOCALAPPDATA%\KosherLink`. אם שמים קובץ ריק בשם `portable.txt` ליד התוכנה, הכל יישמר בתיקייה `data` שלידה.

## התקנה ושימוש

1. מריצים את `dist\KosherLink.exe`.
2. **א. התקנה אוטומטית:** מסמנים הסכמה לתנאי הרישיון של Google ולוחצים. ההורדה היא כ־1.2GB, פעם אחת, ואם היא נקטעת היא ממשיכה מאיפה שעצרה.
3. **ב. רישום:** נפתח חלון הטלפון. מקלידים את המספר של הטלפון הכשר, בוחרים **"Call me"** ומקלידים את הקוד שמקריאים בשיחה.
4. **ג. חיבור למחשב:** בוואטסאפ ל־Windows בוחרים "Log in with phone number" ומקלידים בחלון הטלפון את הקוד בן 8 התווים.
5. **סיום:** מעכשיו יש סמל ירוק ליד השעון. לחיצה כפולה עליו פותחת את וואטסאפ.

### תפריט הסמל (קליק ימני)

| פעולה | מה היא עושה |
|---|---|
| פתח וואטסאפ | פותח את וואטסאפ ל־Windows, או את חלון הטלפון אם הוא לא מותקן |
| הצג את הטלפון הווירטואלי | מציג את המסך, למשל להגדרות חשבון או לחיבור מכשיר. בסגירת החלון המסך נכבה שוב כדי לחסוך משאבים |
| בדוק עדכונים עכשיו | בודק מיד אם יש גרסה חדשה |
| הפעל אוטומטית עם Windows | מפעיל את התוכנה בכל הדלקה של המחשב |
| יציאה | שומר את מצב הטלפון הווירטואלי, כך שההפעלה הבאה מהירה, ומכבה אותו |

## שיחות קוליות ווידאו

השיחות עובדות דרך **וואטסאפ ל־Windows**, עם המיקרופון והרמקולים של המחשב. לטלפון הווירטואלי אין סאונד, כדי לחסוך משאבים, ואין בו צורך.

## גיבוי

- **אוטומטי, פעם ביום:** התוכנה מעתיקה את הגיבוי הלילי שוואטסאפ יוצר בעצמו (קובץ שיחות מוצפן, `msgstore*.crypt*`), יחד עם המדיה החדשה (תמונות, הקלטות, מסמכים). היעד הוא התיקייה `מסמכים\KosherLink Backup`. נשמרים 14 הימים האחרונים.
- **לענן:** בתפריט ← גיבוי ← "בחר תיקיית גיבוי" ← בוחרים תיקייה בתוך Google Drive או OneDrive.
- **גיבוי מלא:** בתפריט ← גיבוי ← "גיבוי מלא של כל הטלפון". זה מעתיק את כל הטלפון הווירטואלי, כ־8GB, ונשמרים 2 עותקים אחרונים.
- **שחזור במחשב חדש:** מעתיקים את `KosherLink Backup` לתיקיית המסמכים, ובאשף לוחצים "שחזור גיבוי" **לפני** הרישום. אחרי האימות בשיחה וואטסאפ יציע "שחזור".
- **שחזור של גיבוי מלא:** סוגרים את התוכנה (יציאה), מעתיקים את תוכן התיקייה `Full\<תאריך>` אל `%LOCALAPPDATA%\KosherLink\avd\KosherLink.avd`, ומפעילים שוב את התוכנה.

הגדרות ב־`config.ini`: `BackupDir`, `BackupMedia` (1/0), `BackupKeepDays`, `BackupKeepFull`.

## דרישות

- Windows 10/11 64 ביט עם 15GB פנויים בדיסק. בפועל התוכנה תופסת כ־13GB: 6GB אחסון לוואטסאפ, כ־4GB רכיבי אנדרואיד, וכ־2GB שמירת מצב להפעלה מהירה.
- זיכרון: מומלץ 8GB ומעלה.
- צריכה במדידה, כשהמסך כבוי: כ־900MB זיכרון וכ־1% מעבד, בעדיפות נמוכה. עלייה מהירה לוקחת כחצי דקה.
- **Windows Hypervisor Platform** צריך להיות מופעל. אם הוא לא מופעל, התוכנה מציעה להפעיל אותו (צריך אישור מנהל והפעלה מחדש).

## הגדרות מתקדמות (`config.ini` בתיקיית הנתונים)

| מפתח | ברירת מחדל | הסבר |
|---|---|---|
| `RamMb` | 2048 | זיכרון לטלפון הווירטואלי. זה המינימום שהאמולטור מאפשר לאנדרואיד 11 |
| `Cores` | 2 | מעבדים |
| `ApiLevel` | 30 | גרסת אנדרואיד (30 = Android 11) |
| `ImageTag` | default | אנדרואיד AOSP נקי. (`aosp_atd` נבדק ולא מציג מסכים של אפליקציות, לכן לא מתאים) |
| `UpdateRepo` | KatzChaim/KosherLink | מאגר GitHub שממנו התוכנה מתעדכנת: הקובץ `KosherLink.exe` מה־Release האחרון, עם בדיקת SHA-256. בדיקה פעם ביום. ערך ריק מבטל את העדכון |
| `UpdateUrl` | (ריק) | מקור עדכון חלופי: כתובת של קובץ JSON בצורה `{"version":"1.0.1","url":"...exe","sha256":"..."}` |

אחרי שינוי של `RamMb`, `Cores`, `ApiLevel` או `ImageTag` צריך למחוק את התיקייה `avd`, ואחר כך להריץ שוב את ההתקנה ואת הרישום.

## בנייה מקוד המקור

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

הבנייה משתמשת במהדר C# שמגיע עם Windows, כך שאין צורך להתקין כלום.

## הערות

- הכל רץ עם האפליקציות הרשמיות, בלי פריצה ובלי עקיפה של וואטסאפ. אי אפשר להבטיח שוואטסאפ לא יבקש אימות נוסף, אבל אם יבקש, מאמתים שוב בשיחה קולית.
- אנשי הקשר לא נמצאים בטלפון הווירטואלי, ולכן בצ'אטים חדשים יוצגו מספרים. שמות נשמרים בתוך וואטסאפ.
- כדי להקליד בעברית בחלון הטלפון הווירטואלי, מעתיקים טקסט במחשב ומדביקים עם Ctrl+V. בוואטסאפ ל־Windows מקלידים כרגיל.
